# GravityCircuit

《重力回路 / Gravity Circuit》Steam 全成就最速攻略静态网页。

## 内容

- 53 个成就
- 英文名 / 中文名
- 解锁条件
- 成就类型
- 最快获取方法
- 必要判定逻辑与容易踩坑的条件
- 页面内搜索、难度筛选、类型筛选

## 使用

直接打开 `index.html` 即可。项目为纯静态 HTML/CSS/JS，无构建依赖。

如果需要在线访问，可以在 GitHub 仓库设置中开启 **GitHub Pages**，Source 选择 `Deploy from a branch`，Branch 选择 `main` / root。
